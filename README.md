🚗 Vehicle-to-Vehicle Safety System

A web-based Vehicle-to-Vehicle (V2V) Safety System simulation that monitors vehicle speed, distance, relative speed, and Time to Collision (TTC) to detect potential collision risks.

✨ Features

🚙 Simulates two vehicles

📡 V2V communication status

⚡ Real-time speed and distance monitoring

⏱️ Time-to-Collision calculation

🟢 Low, 🟠 Medium, and 🔴 High risk levels

🚨 Collision warning system

📋 Real-time event log

📱 Responsive dashboard

🛠️ Technologies

HTML5

CSS3

JavaScript

🚀 How to Run

Clone the repository.

Open the project folder.

Open index.html in any modern web browser.

Adjust the vehicle speed and distance sliders to test different collision scenarios.

⚠️ Note

This project is an educational simulation and does not represent a real-world V2V communication system.
